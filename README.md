# ⚛️ React Admin Panel - Панель управления блогом

![Скриншот дашборда](https://joxi.app/VrwKb5NhvXL5Pr.jpg)

Это полнофункциональная админ-панель для управления контентом блога, созданная с использованием современного стека технологий. Проект демонстрирует навыки построения сложных SPA (Single Page Application), работы с API, управления состоянием и создания качественного пользовательского интерфейса.

---

## 🚀 Основные возможности (Features)

- **🔐 Аутентификация:** Защищенная панель с формой входа и возможностью выхода.
- **🏠 Дашборд:** Наглядная сводка по основным показателям (количество постов, пользователей, комментариев).
- **📄 CRUD для постов:** Полный цикл операций: создание, чтение, редактирование и удаление постов.
- **👤 Управление пользователями:** Просмотр списка пользователей и возможность их блокировки/разблокировки.
- **💬 Модерация комментариев:** Возможность одобрять, отклонять и удалять комментарии.
- **✨ Современный UI:** Чистый и отзывчивый интерфейс, построенный на Material-UI.
- **✔️ Валидация форм:** Продвинутая валидация в реальном времени на формах.

---

## 🛠️ Технологический стек (Tech Stack)

| Технология            | Описание                                                                    |
| :-------------------- | :-------------------------------------------------------------------------- |
| **React**             | Основная библиотека для построения интерфейса.                              |
| **TypeScript**        | Для статической типизации и повышения надежности кода.                      |
| **Vite**              | Современный и быстрый сборщик проекта.                                      |
| **Material-UI (MUI)** | Библиотека готовых UI-компонентов.                                          |
| **React Router**      | Для организации роутинга на стороне клиента.                                |
| **Redux Toolkit**     | Для управления глобальным состоянием (аутентификация).                      |
| **React Query**       | Для работы с серверным состоянием: кэширование, синхронизация данных с API. |
| **React Hook Form**   | Для производительной и удобной работы с формами.                            |
| **Axios**             | Для выполнения HTTP-запросов к API.                                         |
| **JSON Server**       | Для создания фейкового REST API для разработки.                             |

## ⚙️ Как запустить локально

1.  **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/PlagiatXXX/blog-admin-panel.git
    cd blog-admin-panel
    ```

2.  **Установите зависимости (используя pnpm):**

    ```bash
    pnpm install
    ```

3.  **Запустите проект:**
    Эта команда одновременно запустит Vite dev-сервер для фронтенда (`http://localhost:5173`) и `json-server` для бэкенда (`http://localhost:3001`).

    ```bash
    pnpm run dev
    ```

4.  **Откройте приложение в браузере:**
    Перейдите по адресу [http://localhost:5173](http://localhost:5173).
